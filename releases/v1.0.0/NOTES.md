First public release of WWZ Mod.

- **Save editor:** Supplies, Challenge Coins and account level. Steam Cloud and local saves stay in sync, with automatic backups.
- **Class mastery:** level 30 and Prestige 9 for any class, with an option to unlock class skills.
- **Armory:** weapon levels, a skin picker for owned skins, and suggested perks you can unlock.
- **Nexus Mods browser:** only downloads virus-scan-verified files. Mods install reversibly.
- **Steam achievements:** view, unlock or relock them.
- **Play history, backup compare, save export/import.**
- **Appearance:** background art, visibility and blur, accent colours, reduce motion.
- **Built-in updater.**
